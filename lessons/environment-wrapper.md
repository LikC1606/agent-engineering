# 命令名称与实际执行环境不同

适用条件：PATH 中的解释器或编译命令可能是包装脚本、别名或容器入口。

实际观察：一次路径探测中，shell 的工作目录符合预期，但名为 `python3` 的命令进入另一个项目容器，看到不同的文件系统与工作目录，导致错误判断目录不存在。

根因：仅根据命令名称和调用时的工作目录推断真实执行环境。

修复：先检查命令的解析位置与文件类型，再用目标解释器输出自身路径和实际工作目录；后续任务使用已确认的解释器。相同路径探测在正确环境下得到预期结果。

以后识别：文件存在性或工作目录出现矛盾时，先确认包装脚本、挂载与进程内实际路径，再排查业务代码。

关联：C07、C11、C13。该经验不要求所有项目使用同一个绝对解释器路径。
