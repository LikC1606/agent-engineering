# Repository work

This repository packages personal research instructions and small standard-library tools. Keep the original C01–C14 requirements intact and scope the profile to paper-related projects. The canonical operational rules are in `skills/research-engineering/references/rules.md`; platform entry files are generated by `tools/profile.py`.

Supported project adapters are Codex, Claude Code, Cursor, Google Gemini CLI, and Google Antigravity; `--agents` defaults to all five. Codex and Antigravity share the inline `AGENTS.md` region. Gemini uses a native relative import in `GEMINI.md`; all three share `.agents/skills`. Keep rule text single-sourced and shared ownership until the last consumer is uninstalled. Do not modify global context filenames, permissions, or accounts. See `docs/platforms.md` for the discovery contracts and update examples.

Use Python 3.10 or newer and the standard library for runtime tools. Before running a local interpreter, check that it uses the intended environment and working directory. Run `python3 -m unittest discover -s tests -v` after behavioral changes, using disposable temporary projects. Validate the skill frontmatter with the installed skill validator when available.

The installation tool is shared verbatim with `agent-paper-writing`. Maintain one implementation and document synchronized changes. Preserve existing project content, installation history and run attempts. A file-level installation check does not prove that an agent loaded or followed instructions; report these separately.
